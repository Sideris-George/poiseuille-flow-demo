### Project Overview
This interactive simulation explores **Poiseuille's Law**, the fundamental principle governing the flow of fluids through cylindrical tubes. By adjusting variables like vessel radius, fluid viscosity, and pressure gradients, users can visualize how biological flow dynamics change in real-time. 

The model features a **3D Three.js canvas** synchronized with **four dynamic charts**, highlighting the powerful quartic relationship where flow rate is proportional to the fourth power of the radius:

$$Q = \frac{\pi r^4 \Delta P}{8 \eta L}$$

### Key Features
* **Interactive 3D Simulation**: Real-time rendering of blood flow.
* **Particle Physics**: Synchronized Red Blood Cell (RBC) and White Blood Cell (WBC) movement.
* **Live Data Viz**: 2x2 grid tracking Flow ($Q$) against Radius, Viscosity, Length, and Pressure.
* **Responsive Controls**: Fine-tune physical parameters to see immediate physiological effects.
